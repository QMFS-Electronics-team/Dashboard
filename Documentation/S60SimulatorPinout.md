# S60 Simulator Pinout

### Components Used
- 1x Arduino Nano 
- 1x MCP2515 CAN Bus Module
- 7x Potentiometers


### Pinout Table
| Arduino Nano Pin | CAN BUS Module | Potentiometer |
|------------------|----------------|---------------|
| 5V               | VCC            |               |
| GND              | GND            |               |
| D10              | CS             |               |
| D12              | MISO           |               |
| D11              | MOSI           |               |
| D13              | SCK            |               |
| D2               | INT            |               |
| A5               |                | RPM           |
| A4               |                | GEAR          |
| A3               |                | TPS           |
| A2               |                | BPS           |
| A1               |                | OIL TEMP      |
| A0               |                | WATER TEMP    |
